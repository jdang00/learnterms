# v4.5 Paola: DaisyUI → LearnTerms UI migration guide

Design-only migration. Replace DaisyUI component classes with the shadcn-svelte primitives in `$lib/components/ui`, restyled to the LearnTerms brand. **Behaviour must not change**: keep every handler, binding, condition, `aria-*`, `data-*`, `id`, keyboard shortcut and piece of copy. Live reference: `/design-system` (`src/routes/design-system/+page.svelte`).

Theme tokens are already migrated (`text-foreground`, `bg-background`, `bg-muted`, `bg-muted-strong`, `border-border`, `text-muted-foreground`, `*-foreground`). Don't reintroduce `base-100/200/300/content`.

## Rules

- Edit only the files you were assigned. Never edit `src/lib/components/ui/*`, `src/app.css`, `Sheet.svelte`, or this guide. If a primitive can't express something, leave that spot as is and say so in your report.
- Svelte 5 runes. Bun only (`bunx`, never `npx`).
- No new helper or tip text. Comments only where logic isn't obvious.
- Rich HTML stays `{@html sanitizeHtml(x)}` with its eslint-disable line.
- Internal links keep `resolve()` from `$app/paths`.
- Icons: keep the file's existing `lucide-svelte` imports.

## Button (`btn`)

`<Button variant tone size shape loading href disabled class>`. Defaults: `variant="solid" tone="primary" size="md" shape="pill"`.

| DaisyUI                                                       | Button prop                                                                                  |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `btn-primary` … `btn-error`, `btn-neutral`                    | `tone="primary"` … `tone="error"`, `tone="neutral"`                                          |
| plain `btn` (no colour, no style)                             | `variant="soft" tone="neutral"`                                                              |
| `btn-ghost`                                                   | `variant="ghost"`, plus `tone="neutral"` unless a colour class is present                    |
| `btn-outline` / `btn-soft` / `btn-dash` / `btn-link`          | `variant="outline"` / `"soft"` / `"dash"` / `"link"` (add `tone="neutral"` if no colour)     |
| `btn-xs` / `btn-sm` / (none) / `btn-lg`                       | `size="xs"` / `"sm"` / `"md"` / `"lg"`                                                       |
| `btn-circle` / `btn-square`                                   | `shape="circle"` / `shape="square"`                                                          |
| `rounded-full` on a btn                                       | drop it (pill is the default)                                                                |
| `rounded-xl` / `rounded-2xl` / `rounded-lg` on a btn          | `shape="rect"`, drop the class                                                               |
| `btn-block` / `btn-wide`                                      | `class="w-full"` / `class="px-10"`                                                           |
| `btn-active` on a toggle                                      | `aria-pressed={isOn}`                                                                        |
| `btn-disabled`                                                | `disabled`                                                                                   |
| `<span class="loading …">` + label inside, while saving        | `loading={isSaving}` (keep the label)                                                        |
| `<a class="btn" href=…>`                                      | `<Button href=…>`                                                                            |
| `bind:this={el}`                                              | `bind:ref={el}`                                                                              |
| `[--size:…]`, `min-h-0`, `h-auto` DaisyUI sizing hacks        | drop them; use `size`, or `class="size-11"` for an exact square                              |

Keep layout utilities (`w-full`, `flex-1`, `gap-*`, `ms-auto`, `text-*` overrides) in `class`. Colour states that were conditional class strings become conditional props: `tone={correct ? 'success' : 'primary'}`.

Ghost buttons keep their tone in the text. Use `variant="ghost" tone="neutral"` for quiet icon buttons.

## Badge (`badge`)

`<Badge variant tone size>`. Defaults: `variant="soft" tone="neutral" size="sm"`.

- `badge-{tone}` → `tone`. With `badge-soft`, or plain → soft. With a colour and no style → `variant="solid"`.
- `badge-outline` → `variant="outline"`, `badge-dash` → `"dash"`, `badge-ghost` → default soft neutral.
- `badge-xs` → `size="xs"`, `badge-sm` → `"sm"`, (none/`badge-md`/`badge-lg`) → `"md"`.
- Custom non-DaisyUI classes named `badge-*` (e.g. `badge-meta`, `badge-frame`) are app CSS, not DaisyUI. Leave them.

## Dialogs (`modal`)

Use bits-ui dialogs. They portal, trap focus, close on Escape and outside click, and render a close X (`showCloseButton={false}` to hide it).

```svelte
<Dialog.Root bind:open={isOpen}>
	<Dialog.Content class="sm:max-w-lg">
		<Dialog.Header>
			<Dialog.Title>Edit module</Dialog.Title>
			<Dialog.Description>Optional subtitle</Dialog.Description>
		</Dialog.Header>
		<!-- body -->
		<Dialog.Footer>
			<Button variant="ghost" tone="neutral" onclick={close}>Cancel</Button>
			<Button onclick={save}>Save</Button>
		</Dialog.Footer>
	</Dialog.Content>
</Dialog.Root>
```

- Parent-controlled `isOpen` + `onClose` prop: `<Dialog.Root open={isOpen} onOpenChange={(o) => { if (!o) onClose(); }}>`.
- `{#if open}<div class="modal modal-open">…{/if}` and `<dialog class="modal" bind:this={d}>` with `d.showModal()`: replace with a boolean `open` state and `Dialog.Root`. Delete the `<form method="dialog" class="modal-backdrop">` and the `showModal()/close()` calls.
- `modal-box max-w-3xl` → `Dialog.Content class="sm:max-w-3xl"`. Long content: add `max-h-[90dvh] overflow-y-auto`.
- `modal-action` → `Dialog.Footer`.
- Existing `<h3 class="font-bold text-lg">Title</h3>` → `Dialog.Title`.
- Destructive confirmations (delete, reset, discard) → `AlertDialog.Root/Content/Header/Title/Description/Footer/Cancel/Action`. `AlertDialog.Action tone="error"` for destructive, `onclick` on Action runs the handler.
- Phone-first study sheets already use `Sheet.svelte`. Keep them.

## Form controls

- `input` → `<Input bind:value … />` (pill, h-10). Drop `input-bordered`, `w-full` is built in. `input-sm` → `class="h-8 px-3 text-sm"`, `input-xs` → `class="h-7 px-2.5 text-xs"`. `input-error` → `aria-invalid={true}`. `bind:this` → `bind:ref`.
- `<label class="input"><Icon/><input …/></label>` (icon inside the field) → `InputGroup.Root` + `InputGroup.Addon` (icon) + `InputGroup.Input`.
- `textarea` → `<Textarea bind:value />` (rounded-2xl). Drop `textarea-bordered`.
- `<select>` of any kind → `<SelectField bind:value options={[{ value, label }]} placeholder size="sm" />` (bits-ui Select, Luma style). **Never use native selects.** Semester pickers → `<SemesterSelect semesters bind:value />`.
- `checkbox` → `<Checkbox bind:checked />` or `checked={x} onCheckedChange={(v) => …}`. **Not** a native input: `onchange={(e) => e.currentTarget.checked}` becomes `onCheckedChange={(v) => …}`. Sizes: `checkbox-xs` → `class="size-3.5"`, `checkbox-sm` → `class="size-4"`.
- `toggle` → `<Switch bind:checked />` / `onCheckedChange`. `toggle-sm`/`toggle-xs` → `size="sm"`.
- `radio` group → `RadioGroup.Root bind:value` + `RadioGroup.Item value id` + `<Label for>`.
- `range` → `<Slider type="single" bind:value min max step />`.
- DaisyUI `label`/`label-text`/`fieldset`/`fieldset-legend` wrappers → `Field.Field` + `Field.Label` (+ `Field.Description`, `Field.Error`), or `<Label>`.

## Feedback

- `alert alert-error` → `<Alert.Root tone="error"><CircleAlert /><Alert.Title>{msg}</Alert.Title></Alert.Root>`. Tones: error, warning, success, info; plain `alert` → default neutral. Multi-line body → `Alert.Description`. `alert-outline` → `variant="outline"`. Reuse the file's existing icon if it has one.
- `loading loading-spinner` (alone) → `<Spinner />`. Sizes: xs `class="size-3"`, sm `size-4` (default), md `size-5`, lg `size-6`. `loading-dots` etc. also → Spinner.
- `radial-progress` → `<RadialProgress value={v} max={m} tone="success" thickness={3} class="size-12 text-xs">{label}</RadialProgress>` from `$lib/components/ui/radial-progress`.
- `skeleton` → `<Skeleton class="h-4 w-32" />` (keep the size classes).
- `<progress class="progress progress-success" value max>` → `<Progress value={v} max={m} tone="success" />` (default tone primary). Keep height classes like `h-1.5`.

## Overlays and navigation

- `dropdown` + `menu` of actions/links →

```svelte
<DropdownMenu.Root>
	<DropdownMenu.Trigger>
		{#snippet child({ props })}
			<Button {...props} variant="ghost" tone="neutral" shape="circle" aria-label="More"><Ellipsis /></Button>
		{/snippet}
	</DropdownMenu.Trigger>
	<DropdownMenu.Content align="end">
		<DropdownMenu.Item onSelect={edit}><Pencil />Edit</DropdownMenu.Item>
		<DropdownMenu.Separator />
		<DropdownMenu.Item variant="destructive" onSelect={remove}><Trash2 />Delete</DropdownMenu.Item>
	</DropdownMenu.Content>
</DropdownMenu.Root>
```

`dropdown-end` → `align="end"`, `dropdown-top` → `side="top"`, `menu-title` → `DropdownMenu.Label`. Link items: `<DropdownMenu.Item>{#snippet child({ props })}<a {...props} href={resolve('/x')}>…</a>{/snippet}</DropdownMenu.Item>`. Checkable items → `DropdownMenu.CheckboxItem bind:checked`.

- A `dropdown` whose content is a form, picker or custom panel (not a list of actions) → `Popover.Root/Trigger/Content` (same `child` snippet trigger).
- A standalone `menu` (nav list, not a dropdown) → plain `<ul>` of buttons/links with `flex w-full items-center gap-2 rounded-xl px-2.5 py-2 text-sm hover:bg-muted`; active item `bg-muted font-semibold`.
- `tabs`/`tab` → `<Tabs.Root value={tab} onValueChange={(v) => (tab = v)}><Tabs.List><Tabs.Trigger value="a">A</Tabs.Trigger>…</Tabs.List></Tabs.Root>`. Use `Tabs.Content` only if the panels are siblings already; otherwise keep the existing `{#if tab === …}` blocks. `tabs-border`/`tabs-lift` → `<Tabs.List variant="line">`.
- `tooltip` with `data-tip="X"` → `<Tip label="X">…</Tip>`. For a button trigger use the child snippet so the button keeps focus behaviour:

```svelte
<Tip label="Flag question" kbd="F">
	{#snippet child({ props })}<Button {...props} …>…</Button>{/snippet}
</Tip>
```

`tooltip-bottom` → `side="bottom"`. Leave native `title=` attributes alone.

- `join` of buttons → `<ButtonGroup.Root>`; an exclusive choice (segmented control) → `<ToggleGroup.Root type="single" bind:value variant="outline">` + `ToggleGroup.Item value`.
- `collapse` → `Collapsible.Root/Trigger/Content`.

## Data and layout

- `card` → `Card.Root` (rounded-3xl, hairline border, py-6) + `Card.Header/Title/Description/Content/Footer`. `card-body` → `Card.Content`. `card-border` is the default. `card-compact`/`card-sm` → `Card.Root size="sm"`. Hand-built `div` cards that don't use the `card` class: leave them.
- `table` → `Table.Root/Header/Row/Head/Body/Cell`. `table-zebra` → `class="even:bg-muted/50"` on rows. `table-xs/sm` → `class="text-xs"`.
- `kbd` → `<Kbd>`; drop `kbd-xs/sm`.
- `divider` → `<Separator />`; `divider-horizontal` → `orientation="vertical"`. A divider with text → `<div class="flex items-center gap-3 text-xs text-muted-foreground"><Separator class="flex-1" />or<Separator class="flex-1" /></div>`.
- `avatar` → `Avatar.Root` + `Avatar.Image src` + `Avatar.Fallback`. `avatar-placeholder` → just the Fallback.
- `indicator`/`indicator-item` → a `relative inline-flex` wrapper with an `absolute -top-1 -right-1` child.
- `status status-success` → `<span class="inline-block size-2 rounded-full bg-success"></span>`.
- `stats`/`stat`/`stat-title`/`stat-value` → `<div class="rounded-2xl border p-4"><div class="text-xs text-muted-foreground">Title</div><div class="text-2xl font-semibold tabular-nums">Value</div></div>` in a grid.
- `link link-hover` → `underline-offset-4 hover:underline`. `link` → `underline underline-offset-4`. `link-primary` → `text-primary-ink`.
- `footer-title` → `mb-1 text-xs font-semibold text-muted-foreground`. `navbar`, `hero`, `timeline`, `mockup-*`, `chat`, `breadcrumbs`, `toast` → plain Tailwind with the same look.
- `rounded-box` → `rounded-3xl`; `rounded-field`/`rounded-selector` → `rounded-lg`.

## Ink colours (brand contrast)

Text that sits on the page in a role colour should use the ink token: `text-warning` → `text-warning-ink`, `text-success` → `text-success-ink`, `text-info` → `text-info-ink`, `text-error` → `text-error-ink`, `text-primary` → `text-primary-ink`, `text-secondary` → `text-secondary-ink`, `text-accent` → `text-accent-ink`. Icons and fills keep the solid tone (`text-warning` on an icon is fine, `bg-success` stays).

## Verify before reporting

1. `bunx prettier --write <your files>`
2. `bunx eslint <your files>`: fix everything.
3. `bun run check 2>&1 | grep -E "<part of your paths>" -A4`: fix every error in your files. Ignore other files (other workers are editing them in parallel).
4. Leftover check, which should print nothing for your files:

```sh
grep -nE '(class|tone|variant)[^>]*\b(btn|btn-[a-z]+|badge-(xs|sm|md|lg|soft|outline|ghost|dash|primary|secondary|accent|info|success|warning|error|neutral)|modal(-[a-z]+)?|input-(bordered|sm|xs|error)|select-(bordered|sm)|textarea-bordered|checkbox(-[a-z]+)?|toggle(-[a-z]+)?|loading(-[a-z]+)?|alert(-[a-z]+)?|card(-body|-title|-actions|-border)?|dropdown(-[a-z]+)?|menu(-[a-z]+)?|tabs?(-[a-z]+)?|tooltip(-[a-z]+)?|join(-item)?|kbd(-[a-z]+)?|skeleton|progress(-[a-z]+)?|divider(-[a-z]+)?|stats?(-[a-z]+)?|link-hover|footer-title)\b' <your files>
```

(Whole words only. Ignore matches inside identifiers, prop names and app-specific CSS.)

Report: the files you finished, anything you left on DaisyUI and why, and anything a primitive couldn't express.
