# Format Media Interpretation

Template label: `format.media_interpretation`

## Purpose

The skill depends on an image, field, graph, appearance, or diagram.

## Reasoning Order Fit

- Format does not determine order by itself.
- Usually `second` for image/test interpretation and `third` when the media drives diagnosis or management.

## Do Not Use When

The media is decorative or unnecessary.

## Common Stem Patterns

- Analyze the following image.
- What does this appearance suggest?
- Which diagnosis matches this field/graph?

## Anatomy Of This Template

- Stem directs attention to the media.
- Media row has useful alt text or caption when available.
- Correct answer interprets the media.
- Rationale names the visible cue.

## Considerations

- Do not convert visual skills into generic prose.
- Generated media questions should require the media to answer.
- Use solution-only media intentionally, not by accident.

## Production Examples

Each example keeps only the content and semantics needed to understand the template. Source wording is preserved where useful, but new generated questions should use clean wording.

### Example 1: Binocular Vision, Part 1

#### Question Content

- Context: OPT5215 Vision Science III: Motility / Binocular Vision, Part 1
- Format: multiple choice, multi-select
- Stem: Assuming a normal individual with an expected response, which color will seem closer? Further away?
- Options:
  - Blue Closer
  - Blue Further [correct]
  - Red Further
  - Red Closer [correct]
- Rationale: This is due to the idea that shorter wavelengths are refracted MORE than longer wavelengths. So, the blue letters will strike nasal to the fovea, which will project it to the temporal field = UNCROSSED DISPARITY --> Perceived FURTHER AWAY. The red letters do the exact opposite: They strike temporal to the fovea, thus it seems as if it came from the nasal field = CROSSED disparity --> Perceived CLOSER Overall, Yellow light (555nm) is roughly the middle of the spectrum and will land on the fovea with the blue and red straddling the fovea on either side.

### Example 10: Chair Skills

- Stem: This stereopsis test booklet has an awesome anaglyph of the F-22A fighter jet. Which test is this? Which fighter jet would a kiddo with normal stereo reach for if told to reach for the closer one?
- Options:
  - BEST
  - FBAT [correct]
  - PASS Test 3
  - Randot
  - Top right jet [correct]
  - Bottom left jet
- Rationale: This is the F unctional B inocular A ssessment T est (also a Bernell invention funny enough). Looking at the targets without the red/green glasses, it is easy to see there is greater disparity in the smaller of the two planes; when seen in stereo, the top right plane should float closer to the patient than the larger bottom left plane. Patients who suppress an eye's input and use monocular cues for depth, however, will report upon questioning that the larger of the two planes appears closer, since larger objects take up more retinal area, and we learn very early in life that this means "closer." We can easily tell whether a patient is suppressing if they give this response. You can also turn this paper upside down to reverse disparity! All of the anaglyphs can do this, and the jet on the top left would be seen further away.
