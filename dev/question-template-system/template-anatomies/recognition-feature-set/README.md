# Recognition Feature Set

Template label: `recognition.feature_set`

## Purpose

The learner should identify all true features in a category or shared property set.

## Reasoning Order Fit

- Usually `second` order because the learner evaluates several independent claims.
- Can be `first` if the set is direct recall of a short list.

## Do Not Use When

The options are not independently judgeable.

## Common Stem Patterns

- Which of the following are associated with [topic]?
- Which statements are true regarding [topic]?
- Which of these do [items] have in common?

## Anatomy Of This Template

- Stem signals that multiple answers may be correct.
- Every option can be judged independently.
- Correct answers define the category boundary.
- Rationale groups the true features by principle.

## Considerations

- Do not hide multi-select behavior.
- Do not include partially true options unless the course expects nuance and the rationale handles it.
- Use this for category mastery, not random fact bundling.

## Production Examples

Each example keeps only the content and semantics needed to understand the template. Source wording is preserved where useful, but new generated questions should use clean wording.

### Example 2: Binocular Vision, Part 2

#### Question Content

- Context: OPT5215 Vision Science III: Motility / Binocular Vision, Part 2
- Format: multiple choice, multi-select
- Stem: Regarding visual research in monkeys, which of the following is true when binocular deprivation was done?
- Options:
  - Deprivation in the critical period caused an deterioration of visual function such that it never returned to full expected normals [correct]
  - Reverse occlusion following the critical period found some improvement was found
  - In fully mature monkeys, binocular deprivation had no effect on the ocular dominance distribution of cortical neurons [correct]
  - Neurons in the primary visual cortex remained equally responsive to inputs from both eyes despite prolonged closure
- Rationale: Monkey research on binocular deprivation closely parallels Hubel & Wiesel's cat experiments and reinforces the concept of a critical period. Monkeys raised in total darkness from ~2 weeks to 3-6 months of age deteriorated below their birth-level visual function, behaving essentially as blind. While some recovery occurred afterward, they never reached the normal visual function of their peers. This mirrors the cat finding that deprivation during the critical period (weeks 4-12) caused irreversible cortical changes. In both species, reverse occlusion or restored visual input after the critical period failed to rescue the deprived neurons. In fully mature animals of both species, binocular deprivation had no meaningful effect on cortical organization, confirming the window had closed. The convergent finding across cats and monkeys is that the visual cortex has a narrowly timed developmental window during which experience shapes its permanent architecture. Deprive during it and the damage is largely irreversible; deprive after it and the cortex is largely indifferent. The system is actively being developed by input, and what it doesn't receive during that window, it never fully recovers.

- Rationale: This is the F unctional B inocular A ssessment T est (also a Bernell invention funny enough). We can easily tell whether a patient is suppressing if they give this response. You can also turn this paper upside down to reverse disparity!
