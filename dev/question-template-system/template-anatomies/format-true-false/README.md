# Format True False

Template label: `format.true_false`

## Purpose

One claim is worth evaluating directly.

## Reasoning Order Fit

- Format does not determine order.
- Use `first` for a direct fact claim and `second` for a mechanism or distinction claim.

## Do Not Use When

The claim is trivial or has unhandled exceptions.

## Common Stem Patterns

- [Concept boundary claim].
- [Mechanism claim].
- [Comparison claim].

## Anatomy Of This Template

- Stem is a single clear claim.
- Answer is true or false.
- Rationale explains the boundary.
- No hidden qualifiers are required.

## Considerations

- Avoid absolutes unless they are true.
- True/false is strong for misconception correction.
- The rationale carries most of the teaching value.

## Production Examples

Each example keeps only the content and semantics needed to understand the template. Source wording is preserved where useful, but new generated questions should use clean wording.

### Example 1: Binocular Vision, Part 2

#### Question Content

- Context: OPT5215 Vision Science III: Motility / Binocular Vision, Part 2
- Format: true/false
- Stem: A person with eccentric fixation does not necessarily have anomalous correspondence, but a person with anomalous correspondence has eccentric fixation.
- Options:
  - True [correct]
  - False
- Rationale: True! Eccentric fixation (EF) and anomalous correspondence (AC) are related but distinct adaptations. EF is a monocular condition where the deviated eye uses a non-foveal point for fixation instead of the fovea, and this can occur simply from motor habituation without any binocular involvement. AC, on the other hand, is a binocular sensory adaptation where the brain remaps retinotopic connections to pair the fixing eye's fovea with a non-foveal point in the deviating eye, allowing both eyes to share a common visual direction and avoid suppression. Because AC establishes a new "pseudo-fovea" in the deviating eye under binocular conditions, that same point will naturally be used for fixation under monocular conditions, meaning AC always brings EF along with it. However, since EF can develop from simple motor habituation alone without any binocular remapping, a patient can have EF without AC. This is why the statement is true: EF does not necessarily imply AC, but AC always implies EF.

#### Why This Is Good

- Learning target: format.true_false in OPT5215 Binocular Vision, Part 2.
- Stem function: it frames the learner's task as one claim is worth evaluating directly.
- Stem quality: the stem stays focused and does not add unnecessary setup.
- Answer design: The 2 options create a single-best-answer decision with near-neighbor distractors.
- Correct answer role: True
- Rationale role: it teaches the underlying rule and gives transfer value beyond answer confirmation.
- What to emulate: keep the same alignment between stem task, answer format, and rationale purpose.

### Example 8: Verification of GP Lenses

- Options:
  - True [correct]
  - False
- Rationale: A radiuscope can be used to measure center thickness of a GP by placing the lens on the mount in the same manner as that for measuring the front surface radius, but without water. The distance between the images is the apparent thickness (use the fine focus because it is a small distance). Multiply the apparent thickness by the index (n) of the lens material to get the true thickness in mm.
