# Recall Definition

Template label: `recall.definition`

## Purpose

The learner needs to retrieve a named concept, definition, structure, abbreviation, or high-yield association.

## Reasoning Order Fit

- Usually `first` order.
- Use `second` only when the learner must apply the definition to a brief consequence or test result.

## Do Not Use When

The source supports a richer decision, comparison, or management task.

## Common Stem Patterns

- What is the name of [definition]?
- [Description] is known as which term?
- Which term refers to [definition]?

## Anatomy Of This Template

- Stem gives a precise definition or description.
- Correct answer is the exact term or accepted synonym.
- Distractors belong to the same vocabulary family.
- Rationale adds a memory hook or explains the boundary.

## Considerations

- Do not overload the stem with case details.
- Use fill-in-the-blank when exact spelling, abbreviation, or synonym recognition matters.
- Use multiple choice when near-neighbor terms need to be contrasted.

## Production Examples

Each example keeps only the content and semantics needed to understand the template. Source wording is preserved where useful, but new generated questions should use clean wording.

#### Question Content

- Context: OPT5233 Pediatrics / Treatment of Binocular Vision Disorders

- Rationale: Visagraph- Records eye movements during silent reading using infrared sensors, providing objective data on oculomotor function and reading efficiency. Useful for identifying tracking deficits that may contribute to reading difficulties. Developmental Eye Movement Test (DEM) - A paper-based clinical test evaluating vertical and horizontal oculomotor tracking in children ages 6-13. By comparing performance on vertical versus horizontal number-reading tasks, it helps differentiate between oculomotor dysfunction and visual-verbal automaticity deficits affecting reading. King-Devick (K-D) Test - A rapid sideline screening tool used to identify potential concussion by assessing saccadic eye movements and number naming speed. Originally developed in 1976 to evaluate reading difficulties in children, it was later validated for concussion screening in 2011. RightEye- A commercially available eye-tracking system that objectively measures eye movement patterns for clinical assessment across a range of visual and neurological conditions.

### Example 11: Ocular Health

#### Question Content

- Context: OPT5233 Pediatrics / Ocular Health
- Format: multiple choice, single-best-answer
- Stem: A normal variation is a finding called a Mittendorf dot. This represents the anterior remnant of the hyaloid artery attachment. What is the finding called when the posterior remnant of the hyaloid artery persists at the optic nerve head?
- Options:
  - Toxocara
  - Persistent Hyperplastic Primary Vitreous
  - Morning glory disk
  - Bergmeister's Papilla [correct]
- Rationale: The hyaloid artery runs from the optic disc to the posterior lens capsule during fetal development and normally regresses before birth. It starts to regress at 10 weeks gestation, and should completely be gone by 7 months. Bergmeister's Papilla is the posterior remnant: a glial tuft on the optic nerve head. Generally benign and a normal variant. A Persistent Hyaloid Artery (PHA) occurs when the vessel itself fails to fully regress, appearing as a strand through the vitreous. It is typically unilateral in full term healthy infants, but has a significantly higher incidence in premature infants: reported up to 95%. PFV (Persistent Fetal Vasculature) is complete failure of regression and is a pathological finding requiring urgent referral.
