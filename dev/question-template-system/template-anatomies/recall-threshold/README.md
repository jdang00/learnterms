# Recall Threshold

Template label: `recall.threshold`

## Purpose

The learner needs a number, cutoff, range, timeline, dose, formula, or clinical threshold.

## Reasoning Order Fit

- Usually `first` order when asking directly for a number, range, dose, or cutoff.
- Use `second` when the learner must apply the threshold to decide whether a result is abnormal or meaningful.

## Do Not Use When

The real skill is deciding what to do with the number.

## Common Stem Patterns

- What is the threshold for [criterion]?
- What range is expected for [measurement]?
- Which value best represents [cutoff]?

## Anatomy Of This Template

- Stem names the measurement and clinical context.
- Options include units and plausible nearby values.
- Correct answer is exact enough for grading.
- Rationale ties the number to interpretation or use.

## Considerations

- Always include units.
- Do not mix percentages, ratios, and raw values unless the source does.
- Prefer fill-in-the-blank only when accepted variants are enumerable.

## Production Examples

Each example keeps only the content and semantics needed to understand the template. Source wording is preserved where useful, but new generated questions should use clean wording.

### Example 5: Binocular Vision, Part 2

#### Question Content

- Context: OPT5215 Vision Science III: Motility / Binocular Vision, Part 2
- Format: multiple choice, single-best-answer
- Stem: What percentage of cells in layers 1-3 and 5-6 of the visual cortex are capable of binocular summation?
- Options:
  - ~25%
  - ~50% [correct]
  - ~75%
  - ~100%
- Rationale: After visual information leaves L4, it projects onto neurons in layers 1-3 and 5-6. Here, the first binocular neurons are seen. Binocular neurons are striate cortical simple cells and complex cells: they receive input from BOTH eyes. They are capable of doing binocular summation, where when they are stimulated by both eyes, their firing rage will over double the firing orate of single eye stimulated. Under the right conditions: similar stimuli, similar field, etc, only BINOCULAR cells can do BINOCULAR summation. In these layers, ~50% are binocular cells and the other ~50% are flat neurons that do not sense stereo.
