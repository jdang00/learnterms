# Format Select All

Template label: `format.select_all`

## Purpose

The learner should identify multiple true options from an independently judgeable set.

## Reasoning Order Fit

- Format does not determine order.
- Often `second` because multiple claims are evaluated, but can be `first` for direct list recall or `third` for management bundles.

## Do Not Use When

The question has only one supported answer.

## Common Stem Patterns

- Which of the following are true?
- Select all that apply.
- Which options are recommended?

## Anatomy Of This Template

- Stem makes multiple correct answers expected.
- Options are independently true or false.
- Correct answer set is complete.
- Rationale groups why each correct answer belongs.

## Considerations

- Avoid hidden multi-select.
- Do not make one option a prerequisite for another unless the UI supports it.
- Use for category boundaries and management bundles.

## Production Examples

Each example keeps only the content and semantics needed to understand the template. Source wording is preserved where useful, but new generated questions should use clean wording.

### Example 2: Binocular Vision, Part 2

#### Question Content

- Context: OPT5215 Vision Science III: Motility / Binocular Vision, Part 2
- Format: multiple choice, multi-select
- Stem: Regarding visual research in monkeys, which of the following is true when binocular deprivation was done?
- Options:
  - Deprivation in the critical period caused an deterioration of visual function such that it never returned to full expected normals [correct]
  - Reverse occlusion following the critical period found some improvement was found
  - In fully mature monkeys, binocular deprivation had no effect on the ocular dominance distribution of cortical neurons [correct]
  - Neurons in the primary visual cortex remained equally responsive to inputs from both eyes despite prolonged closure
- Rationale: Monkey research on binocular deprivation closely parallels Hubel & Wiesel's cat experiments and reinforces the concept of a critical period. Monkeys raised in total darkness from ~2 weeks to 3-6 months of age deteriorated below their birth-level visual function, behaving essentially as blind. While some recovery occurred afterward, they never reached the normal visual function of their peers. This mirrors the cat finding that deprivation during the critical period (weeks 4-12) caused irreversible cortical changes. In both species, reverse occlusion or restored visual input after the critical period failed to rescue the deprived neurons. In fully mature animals of both species, binocular deprivation had no meaningful effect on cortical organization, confirming the window had closed. The convergent finding across cats and monkeys is that the visual cortex has a narrowly timed developmental window during which experience shapes its permanent architecture. Deprive during it and the damage is largely irreversible; deprive after it and the cortex is largely indifferent. The system is actively being developed by input, and what it doesn't receive during that window, it never fully recovers.

### Example 4: Binocular Vision, Part 1

- Context: OPT5215 Vision Science III: Motility / Binocular Vision, Part 1
- Format: multiple choice, multi-select
- Stem: Assuming a normal individual with an expected response, which color will seem closer? Further away?
- Options:
  - Blue Closer
  - Blue Further [correct]
  - Red Further
  - Red Closer [correct]
- Rationale: This is due to the idea that shorter wavelengths are refracted MORE than longer wavelengths. So, the blue letters will strike nasal to the fovea, which will project it to the temporal field = UNCROSSED DISPARITY --> Perceived FURTHER AWAY. The red letters do the exact opposite: They strike temporal to the fovea, thus it seems as if it came from the nasal field = CROSSED disparity --> Perceived CLOSER Overall, Yellow light (555nm) is roughly the middle of the spectrum and will land on the fovea with the blue and red straddling the fovea on either side.

- Options:
  - BEST
  - FBAT [correct]
  - PASS Test 3
  - Randot
  - Top right jet [correct]
  - Bottom left jet
- Rationale: This is the F unctional B inocular A ssessment T est (also a Bernell invention funny enough). Looking at the targets without the red/green glasses, it is easy to see there is greater disparity in the smaller of the two planes; when seen in stereo, the top right plane should float closer to the patient than the larger bottom left plane. Patients who suppress an eye's input and use monocular cues for depth, however, will report upon questioning that the larger of the two planes appears closer, since larger objects take up more retinal area, and we learn very early in life that this means "closer." We can easily tell whether a patient is suppressing if they give this response. You can also turn this paper upside down to reverse disparity! All of the anaglyphs can do this, and the jet on the top left would be seen further away.
